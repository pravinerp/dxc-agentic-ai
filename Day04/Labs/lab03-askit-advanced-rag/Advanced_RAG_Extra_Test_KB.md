## VPN Error 809

If a user receives **VPN error 809**, first verify that the corporate network is reachable. If the problem continues, switch the VPN profile to **BLR-2** and reconnect.

## VPN Stability

Some users describe the issue without using the word "disconnect". They may say:
"The secure tunnel drops repeatedly during long calls."
For repeated VPN drops, reconnect using the latest VPN client and check whether the network is switching between Wi-Fi access points.

## Password Guidance

Current password guidance requires a minimum password length of **14 characters**.

## Personal Device Guidance

Employees may use an approved personal laptop for VPN only after device enrolment, encryption, and security compliance checks are complete.

Contractors must use an organisation-issued laptop for VPN access.

## Printer Migration

## A Relevant but Incomplete VPN Passage

The VPN service provides encrypted remote access to internal systems. It supports employees working from approved locations and uses multi-factor authentication.

## A More Direct VPN Passage

When users ask how often the VPN disconnects, the support team should first determine whether the connection drops repeatedly or only during network hand-offs. Repeated drops should be investigated using client logs and access-point changes.
