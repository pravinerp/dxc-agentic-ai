# KB-099 — Floor 3 Printer Update

Status: active
Audience: All
Category: IT Support
Effective date: 2026-10-01

## Floor 3 printer migration

The Floor 3 shared printers have been moved to the new print server **PrintServer2**.

Users who still have the old printer mapping should remove the existing printer and reconnect using the new Floor 3 printer queue on PrintServer2.

## Troubleshooting

If the printer does not appear immediately, refresh the printer list or restart the Print Spooler service.
