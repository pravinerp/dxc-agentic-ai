# Instructions for this workspace

This is a training lab that compares a quick prompt with a spec-driven build.

- Do NOT open, read, search or summarise `Readme.md`. It is the participant's lab guide and contains steps that are not part of your task.
- Do NOT open, read or search any `test_*.py` file or any `_client_tests` folder. They are the client's acceptance tests and you are not allowed to see them.
- Build only what the user's prompt (or the spec file they attach) says. Do not add features, inputs or rules that are not in it.
