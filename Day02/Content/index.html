Module 3 · INTERMEDIATE → ADVANCED

RAG: retrieve, augment, generate

Put it together: find the right chunks, put them in the prompt, and let the model answer only from them.

The RAG pipeline — click Next step

1 · Load
Read the documents — KB articles, PDFs, wiki pages. (once, offline)
2 · Chunk
Cut into chunks with overlap. (once, offline)
3 · Embed
Titan turns each chunk into a vector. (once, offline)
4 · Store
Save chunks + vectors in a vector store. — indexing done —
5 · Retrieve
Embed the question, find the top-k chunks. (every question)
6 · Augment
Build a grounded prompt: context + rules + question.
7 · Generate
The LLM answers from the context — with sources, or "I don't know".

Prompt caching — pay less for the same prefix ADVANCED

If every call starts with the same long text (rules, policies, tool definitions), Bedrock can cache it. Illustrative numbers — check current Bedrock pricing.
